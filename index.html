📖 PETUNJUK PETUALANGAN

  1. Tekan Mulai Game. Game mengambil 10 soal secara acak dari 35 soal master.
  2. Setiap soal memiliki waktu 15 detik. Baca pertanyaan dan dua pilihan jawaban.
  3. Zona kiri = A (hijau), zona kanan = B (cokelat). Aktifkan kamera dan berdirilah di tengah; bergerak ke kiri/kanan untuk memilih.
  4. Pelacakan kamera membaca perubahan gerakan pada gambar webcam. Arahkan gerakan tubuh dengan jelas dan kembali ke tengah setelah setiap jawaban.
  5. Jika kamera tidak tersedia atau tidak akurat, gunakan tombol A dan B, atau keyboard A/B.
  6. Jawaban benar mendapat 10 poin. Maksimum skor adalah 100.

Catatan kamera: pelacakan gerakan berjalan lokal dengan Canvas API (tanpa internet / model eksternal). Ini bukan pelacakan kerangka tubuh berbasis AI. Browser dapat meminta izin kamera; dukungan kamera bergantung pada browser dan cara file dibuka.
